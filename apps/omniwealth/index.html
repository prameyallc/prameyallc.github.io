OmniWealth

For people learning how money works

How money concepts actually work, explained with sources you can check, plus tools to run your own numbers. It never recommends a product or an allocation — that isn't the gap it fills.

OmniWealth is a cited library of how money concepts work, and a place to run numbers you type yourself. It has no bank or brokerage connection, and it does not pick a product for you.
