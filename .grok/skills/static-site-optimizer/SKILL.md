---
name: static-site-optimizer
description: Keep the Prameya company site fast, accessible, and GitHub Pages compatible. Use when touching HTML/CSS, the builder, sitemap, or .nojekyll, or when the user runs /static-site-optimizer.
---

Read `SITE.md` for the sitemap and domain notes.

- Pages are generated by `src/build_site.py`. Keep `.nojekyll`.
- Unique title, description, and canonical on every page.
- Skip link, `:focus-visible`, `prefers-reduced-motion`, contrast on small type.
- No runtime JS unless CSS cannot do the job.
- After changes: `python3 src/build_site.py && python3 -m unittest tests.test_site -v`.
- Do not add `privacy/` to this repo.
